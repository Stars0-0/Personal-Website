Projects

AI recommendation engine

Python, TF-IDF, cosine similarity

A content-based recommender that matches a user's skills to job roles. TF-IDF weights specific skills above generic ones, and cosine similarity ranks the roles. Each request moves through four stages (ingest, score, sort and filter), and new users with no history are detected as cold starts.

Try it: match skills to roles

A small JavaScript version of the same idea, run on a made-up list of 7 roles. Pick the skills you have. Rare skills like PyTorch count for more than common ones like Python.

    ML classification pipeline

    Python, scikit-learn, pandas

    An end-to-end KNN classifier. Features are standardized, the data is split 80/20, and the best value of K is chosen automatically. Results are judged with a confusion matrix and F1 score, not accuracy alone.

    Try it: classify a point with KNN

    Click or drag on the chart, or use the sliders. The point takes the majority class of its k nearest neighbours, outlined in white inside the dashed ring. Try k = 1, then k = 15.
